# 05｜避免意外与家庭急救（安稳走过一生的护栏）

> 狗生最大的黑天鹅往往不是基因绝症，而是**一秒钟没盯住的“偷吃、没牵绳、误食玩具和人用药”**。花极小成本把家里的物理防线做好，就能避开 80% 的突发急诊。

---

## 5.1 厨房与家庭“高危杀手清单”（全员背熟，来客人先打招呼）

| 高危物品 | 毒理机制与真实后果 | 防坑重点与证据等级 |
| :--- | :--- | :--- |
| **葡萄 / 提子 / 葡萄干 / 塔塔粉** | 含有**酒石酸（Tartaric acid）**，犬类肾近端小管缺乏代谢转运能力，可致**急性肾衰竭**，个体敏感度差异极大，**没有安全剂量** | **糯米实战案例**：偷吃提子后千万别等“看它吐不吐”，立刻就医催吐是性价比最高、最稳妥的选择！（A 级，Wegenast et al., *JAVMA* 2021 / *JVECC* 2022 / ASPCA） |
| **高油脂人类食物**（烤鸭肥肉/肥皮、烧烤、红烧肉、坚果） | 瞬间刺激胰酶异常激活，极易诱发**急性胰腺炎**（剧痛、住院、花钱且易留慢性复发隐患） | **糯米实战案例**：偷吃带皮烤鸭肥肉 → 指标超标 10 倍 → 住院花掉 5,000 元！带盖垃圾桶 + 餐桌清场是零成本刚需。（A 级 + M 级） |
| **木糖醇（Xylitol）** | 极小剂量即引起犬类胰岛素暴增，导致**致命低血糖**与急性肝坏死 | 隐藏在无糖口香糖、部分牙膏、无糖蛋糕与部分花生酱中。（A 级，ASPCA） |
| **洋葱 / 大蒜 / 韭菜 / 大葱** | 破坏红细胞引发**溶血性贫血**（煮熟、油炸、洋葱粉全部有毒！） | 外卖炒菜汤汁、烤肉串是最常见隐形雷区。（A 级，ASPCA） |
| **巧克力 / 可可 / 咖啡因** | 可可碱中毒，引发呕吐、心律失常、抽搐（黑巧/烘焙可可粉毒性最高） | 体型越小的狗致死剂量越低。（A 级，ASPCA） |
| **人类止痛/感冒药** | **布洛芬、对乙酰氨基酚（扑热息痛）、阿司匹林**可致胃穿孔或急性肝肾衰竭 | **绝对不要擅自给狗吃任何人类退烧止痛药！**家里药箱务必上锁或放高处。（A 级，Merck） |
| **发声玩具哨子 / 袜子 / 绳线 / 熟禽骨** | 吞咽造成消化道穿孔或线性异物梗阻，严重需开腹手术（费用 5,000–15,000+ 元） | 像糯米一样“通宵也要把哨子咬出来”的狗子：**玩具一咬破立刻没收，不留发声玩具与狗独处过夜**。（C 级 / M 级） |
| **常见有毒家庭绿植** | 百合（对猫极剧毒、对狗也有胃肠刺激）、滴水观音、绿萝、苏铁（铁树种子剧毒）、杜鹃等 | 养狗家庭买植物前先查 ASPCA 植物毒理库。（B 级，ASPCA） |

## 5.2 误食后的黄金急救与“严禁催吐”红线
- **正确动作**：
  1. 冷静记录 3 个关键信息：**吃了什么（拍配料表/实物）+ 大概吃了多少 + 距离现在过了多久**；
  2. 误食提子、巧克力、非腐蚀药物等，黄金催吐窗口通常在 **1–2 小时内**，立刻联系最近医院进行专业药物催吐（比在家瞎折腾安全高效得多）。
- **四条严禁自行催吐红线**（越线可能当场要命）：
  1. 吞食了**尖锐物**（骨头、针、玻璃、硬塑料碎片）——催吐会二次划破食道；
  2. 吞食了**腐蚀性或起泡液体**（洁厕灵、消毒液、漂白剂、油漆）；
  3. 狗已出现**昏迷、抽搐、极度虚弱或呼吸困难**——极易吸入呕吐物窒息；
  4. **绝对不要信偏方灌大量浓盐水催吐**——可引发致命高钠血症！
- **证据等级**：A 级（ASPCA / Merck 急诊指南）

## 5.3 夏季中暑急救（短鼻犬与厚毛犬头号隐形杀手）
- **早期信号**：剧烈喘气停不下来、狂流黏稠口水、牙龈深红/发紫、步态不稳、呕吐腹泻、直肠体温 > 40°C。
- **现场降温正确动作**：
  - 立刻转移至阴凉空调处，用**常温凉水（绝不要用冰水或冰块直接敷全身！冰水会导致体表血管剧烈收缩反而锁住内脏热量）**打湿腹部、腋下、腹股沟和爪垫，配合风扇加速蒸发；
  - 降温同时**立刻送医**（即使体温降下来，中暑引发的凝血异常与肾损伤常在 24–72 小时内延迟爆发！）。
- **预防成本**：0 元（夏天避开上午 10 点–下午 5 点暴晒时段遛狗，**手背贴地面 5 秒觉得烫，狗爪就绝对受不了**；绝对不要将狗单独留在熄火的车内，即使只有 5 分钟！）。
- **证据等级**：A 级（Merck / AAHA 急诊指南）

## 5.4 出门防意外低成本“三件套”
1. **合身防挣脱胸背 + 牵引绳（永远牵绳）**：几十元挡掉车祸、咬架纠纷、走失和误食路边毒饵，全书安全类性价比第一。
2. **身份铭牌（刻手机号）+ 芯片**：铭牌十几元永不断电，比动辄几百还需充电的定位器更稳妥。
3. **正向嘴套脱敏**（严重捡食癖狗子必备）：选用可张嘴喘气喝水的**大口径篮式嘴套**，提前涂花生酱（无木糖醇）/肉泥做正向脱敏，出门防捡食毒饵、腐肉和鸡骨头极省心。
