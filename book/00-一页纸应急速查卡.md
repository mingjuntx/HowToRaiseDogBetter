## 1. 成年犬正常生命体征基准（Merck 兽医手册，A 级）

| 指标 | 正常参考值 | 立刻拉响红灯 |
| :--- | :--- | :--- |
| **直肠体温** | **38.3°C – 39.2°C**（勿用水银体温计！） | **> 39.5°C**（高烧/中暑）或 **< 37.5°C**（低体温/休克） |
| **牙龈颜色** | **湿润粉红色** | 苍白/发白、发青发紫、发黄、有出血点 |
| **毛细血管再充盈（CRT）** | 按压牙龈变白后松手 **1–2 秒恢复粉红** | **> 2 秒**（脱水/灌注不足/休克） |
| **熟睡呼吸频率** | **18–34 次/分**（静息常 < 30 次/分） | 熟睡时持续 **> 35–40 次/分**、张口费力喘、腹式剧烈抽动 |
| **心率** | **70–120 次/分**（小型犬/幼犬可达 140–160） | 静息极快、极慢或明显节律紊乱 |

## 2. 呕吐 / 急症“立刻送 24h 急诊”红灯清单

出现以下任意一条，**不要在网上问来问去，立刻带狗去医院**：
- 呕吐物呈**咖啡渣样（黑褐色颗粒）**、**大量鲜血**或伴黑便/血便；
- **反复干呕吐不出 + 腹部迅速胀大 + 狂流口水焦虑**（疑似胃扭转 GDV，几小时致命！）；
- **24 小时内频繁呕吐 ≥ 2–3 次**，或伴明显萎靡、拒食拒水、摆出**“祈祷姿势”**（前肢趴地屁股撅起——高度警惕急性胰腺炎或剧烈腹痛）；
- 确认或怀疑误食**葡萄/提子、木糖醇、洋葱大蒜、巧克力、人用止痛感冒药、老鼠药/异烟肼、玩具哨子/尖锐异物**；
- 突然抽搐、昏迷、牙龈发白/发紫、后肢突然拖行瘫痪、持续排尿不出（尿闭）。

## 3. 绝对致命食物与毒物（零容忍，ASPCA A 级）

| 类别 | 危险物品 | 核心危害 |
| :--- | :--- | :--- |
| **水果/烘焙** | **葡萄、提子、葡萄干、塔塔粉** | 酒石酸致急性肾衰竭（**无安全剂量**） |
| **代糖** | **木糖醇**（无糖口香糖、部分牙膏/零食） | 极速致死性低血糖、急性肝坏死 |
| **调味/葱属** | **洋葱、大蒜、韭菜、大葱**（熟的也有毒） | 溶血性贫血 |
| **零食/饮品** | **巧克力、可可粉、咖啡、茶、酒精** | 心律失常、抽搐 |
| **人类药物** | **布洛芬、对乙酰氨基酚（扑热息痛）、阿司匹林** | 胃穿孔、急性肝肾衰竭 |
| **高脂人饭** | **烤鸭肥肉/肥皮、油炸、烧烤、高油汤汁** | 极易诱发**急性胰腺炎**（糯米亲历！） |

## 4. 误食催吐黄金原则与“严禁催吐”红线
- **黄金窗口**：误食无尖锐/无腐蚀毒物（如提子、巧克力）后 **1–2 小时内**，立刻带残余包装赴医院评估催吐。
- **严禁自行催吐**：吞食**尖锐物**（骨头/塑料碎片/针）、**腐蚀性液体**（洁厕灵/漂白剂）、狗已**意识模糊/抽搐/呼吸困难**；**绝对不要灌大量盐水**（可致高钠血症中毒！）。
