# 03｜吃喝、防病与反智商税（全年龄段长寿基建）

> 宠物消费市场 70% 的焦虑营销都在卖“让你心理安慰”的东西；真正拉长狗子健康寿命的，往往是最便宜、最枯燥的几件底层小事。

---

## 3.1 【全书 ROI 第一】控制体况评分（BCS），别把狗喂胖
- **建议**：买一个 20 元厨房电子秤按克喂粮，将零食热量计入每日总摄入（不超过总热量 10%）；每月摸一次肋骨和腰线，将体况维持在 **WSAVA 9 分制体况评分的 4–5 分**（轻摸能轻松摸到肋骨但肉眼不突兀、俯视有清晰腰线、侧视腹部上收）。
- **投入成本**：**负成本**（省狗粮钱）+ 20 元电子秤。
- **说人话**：觉得“胖乎乎可爱”而心软多喂，是在透支它的晚年关节、心脏和寿命；保持精瘦体态是全地球最便宜、证据最硬的“延寿神药”。
- **硬核收益**：经典的拉布拉多终身对照研究（Kealy et al., *JAVMA* 2002）证实，维持精瘦体况（控食 25%）的狗**中位寿命延长了 1.8 年（约 15%，13.0 岁 vs 11.2 岁）**，髋关节骨关节炎等慢性退行性疾病显著推迟，胰岛素敏感性更佳。
- **性价比档位**：极高｜**证据等级**：A 级（终身 RCT + WSAVA 全球营养评估指南）

---

## 3.2 居家刷牙：一年 100 元，省下几千元全麻洗牙
- **建议**：每周至少使用**宠物专用酶牙膏 + 软毛小头牙刷/指套**刷牙 **3 次以上**（理想每天 1 次），重点刷上颌后槽牙外侧（牙结石重灾区）。
- **投入成本**：牙膏牙刷年花费约 80–150 元，每次 1–2 分钟。
- **说人话**：3 岁以上的狗绝大多数都有不同程度的牙周问题。牙结石不只是口臭，细菌还会经牙龈毛细血管进入血液，长期损伤肾脏和心脏瓣膜；等到重度牙周炎全麻洗牙甚至拔牙，一次费用轻松 **1,500–4,000 元**。
- **避坑提醒**：洁齿骨、漱口水、洁牙粉只能起辅助作用，**物理摩擦刷牙不可替代**；绝对禁止使用人类含氟或含木糖醇的牙膏！
- **性价比档位**：极高｜**证据等级**：A 级（WSAVA / AAHA 牙科指南）

---

## 3.3 疫苗与驱虫：抓核心、查批文、按风险做
- **核心疫苗必打**：犬瘟热（CDV）、犬腺病毒（CAV-2）、犬细小病毒（CPV-2）+ **狂犬病疫苗**（中国属狂犬病流行区且属法规强制）。幼犬按规范打完基础针 + 1 年加强针后，成年犬可结合抗体滴度检测与当地狂犬免疫法规评估加强间隔，不必盲目多打非核心针。
- **科学驱虫**：
  - 常去草地、公园、灌木丛的狗，**春夏季/南方全年按月做好体外驱虫**（重点防蜱虫传播的巴贝斯虫等致命血液寄生虫）与定期体内/心丝虫预防；
  - **防假药动作**：网购驱虫药务必查看包装上的“兽药字/进口兽药注册证号”，并在**农业农村部“国家兽药基础信息查询”系统**核验真伪。
- **性价比档位**：极高｜**证据等级**：A 级（WSAVA 疫苗指南 / CAPC 寄生虫指南）

## 3.4 吃喝与营养补剂“红黑榜”（反智商税速查）

| 类别 | 性价比档位 | 理性评估与证据 |
| :--- | :--- | :--- |
| **正规品控稳定的全价主粮**（符合 AAFCO / FEDIAF 标准） | **极高** | 选粮重点看**品牌长期品控记录、配料透明、营养达标以及你家狗吃完的粪便/皮毛/泪痕反馈**；不必迷信“天价网红粮”或盲目跟风“无谷”（FDA 曾提示部分无谷豆类高占比配方与扩张型心肌病存在潜在关联线索）。（B 级） |
| **高纯度 Omega-3 鱼油（EPA/DHA）** | **高** | 在皮肤屏障、关节抗炎、肾脏与心血管支持方面有较扎实临床证据。⚠️ **有胰腺炎病史的狗（如糯米），任何油脂类补剂都必须在兽医指导下严格核算总脂肪量！**（A–B 级） |
| **兽医特定菌株益生菌**（软便/换粮/寄养应激期短期用） | **中高** | 帮助缩短急性应激腹泻病程；健康状态良好、便便成型时没必要天天当饭吃。（B 级） |
| **高价“去泪痕粉 / 爆毛神粉 / 排毒营养膏”** | **避坑（负性价比）** | 泪痕多由鼻泪管堵塞、倒睫、耳道/眼部感染或食物过敏引起，吃所谓“去泪痕粉”极易交智商税，甚至个别劣质产品违规添加抗生素。（C 级） |
| **长期随意喂人饭、肥肉、熟骨头** | **高危避坑** | 熟禽骨易刺穿消化道，高盐高油直接诱发急性**胰腺炎**（糯米偷吃烤鸭肥肉的 5,000 元教训！）。（A 级） |

## 3.5 不同年龄段的“吃喝拉撒与体检”关注点速查

| 年龄阶段 | 日常核心关注点 | 推荐体检频率与必查项（AAHA 生命阶段指南，A 级） |
| :--- | :--- | :--- |
| **幼犬期（0–1 岁）** | 幼犬全价粮、按时完成核心疫苗与驱虫、定点排泄、护食预防、社会化与身体脱敏 | 接回家基础体格检查 + 传染病快筛；1 岁前完成绝育评估 |
| **青壮年期（1–6 岁）** | **严控 BCS 体重**、坚持刷牙、防意外误食与高油人饭（如糯米目前 4 岁多，重点防胰腺炎复发与发声玩具吞咽） | **每 1 年 1 次**：体格检查（含口腔/体重/听诊）+ 血常规 + 基础生化 + 尿检（建好健康基线！） |
| **中年转老年（小型犬 7 岁+ / 大型犬 6 岁+）** | 监测饮水/排尿量变化、观察起卧僵硬与夜间干咳、开始居家防滑等适老化改造 | **升级为每半年 1 次**：全面血常规与生化 + 尿液分析 + **肾脏早筛（SDMA）+ 血压 + 心脏听诊/心超 + 腹部 B 超** |
